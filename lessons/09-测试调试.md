# 第 9 课：从症状找到责任层

## 三种验证，不要混为一谈

纯逻辑测试不启动 Maya，验证规则和数据转换；Maya 集成测试启动单独 mayapy，验证插件和场景行为；界面验收在交互 Maya 中验证窗口、操作感受和文件对话框。通过前两种，不代表第三种自动通过。

在 PowerShell 中进入课程目录，替换下面的 Maya 安装路径：

```powershell
& 'C:\Program Files\Autodesk\Maya2026\bin\mayapy.exe' -m unittest discover -s tests -p 'test_*.py' -v
& 'C:\Program Files\Autodesk\Maya2026\bin\mayapy.exe' tests/run_maya.py
```

第二条只在**独立进程**执行；不要把 run_maya.py 粘进正在工作的 Maya，它会替换测试场景。纯逻辑测试默认验收参考答案；练习 starter 故意留空，不算已完成。

## 测什么比测多少更重要

本课程检查阈值边界、无选择、非法参数、输入不被修改；命令检查撤销重做、锁定对象不造成部分修改、场景单位变化；节点检查连接、输入变脏后的重算、保存重开。

不必测试“给变量赋值后变量等于这个值”这种复述实现的行为。应测试用户真正依赖的契约，特别是失败后的状态。

## 一个实战调试记录

开发本例时，最初把 Python API 2.0 的 MArgList 写成 `args.length()`，执行报 AttributeError。修正为 `len(args)` 后命令测试通过。这个错误说明：知道另一个 API 的形式不代表当前绑定也相同。

定位步骤：读异常最后一行 → 找到文件/行号 → 检查对象类型 → 查询当前版本接口 → 最小改动 → 重跑对应测试。不要看到命令失败就同时修改 UI、插件路径和场景单位。

## 按责任层缩小问题

| 症状 | 优先检查 |
|---|---|
| import 失败 | sys.path、包目录层级、模块名称 |
| UI 点击无结果 | 信号连接、异常堆栈、按钮状态 |
| 面数错误 | 选的是 transform 还是 shape、intermediate、是否误把多边面当三角形 |
| 重做移动了别的对象 | redoIt 是否重新读取选择 |
| 节点改输入却不更新 | attributeAffects、输出 clean 状态、连接 |
| Maya 与 UE 大小不符 | 单位、导入缩放、变换是否重复应用 |

## 手工界面验收表

- 重复打开只保留一个可用窗口。
- 空选择有明确提示；选择立方体、阈值为 5，出现面数问题。
- 更改模型缩放后重新检查，报告更新。
- 取消保存不写文件；保存后能用文本编辑器读取 JSON。
- 关闭再打开工具，没有重复回调或旧结果误用。

练习：故意删除乘法节点的一条 attributeAffects，记录“预期、实际、最小复现、原因、修复”五项，再恢复源码。不要把带故障版本作为发布包。
