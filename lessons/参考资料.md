# 官方参考资料

教材按项目顺序组织；遇到接口细节，以对应 Maya 版本的官方文档为准。

- [Maya 2026 开发文档](https://help.autodesk.com/view/MAYADEV/2026/ENU/)：开发入口、API 与版本变化。
- [命令插件基础](https://help.autodesk.com/cloudhelp/2019/ENU/Maya-SDK-MERGED/developer/Maya-Python-API/Maya-Python-Plug-in-Learning/Command-Plug-in-Basics/Command-Plug-ins.html)：注册与命令生命周期，较早版本文档，具体接口对照本机版本。
- [依赖图插件基础](https://help.autodesk.com/cloudhelp/2022/ENU/Maya-SDK/Maya-Python-API/Dependency-Graph-Plug-in-Basics/Dependency-Graph-Plug-ins.html)：节点、属性与求值。
- [Python API 2.0 MPxNode](https://help.autodesk.com/cloudhelp/2024/ENU/MAYA-API-REF/py_ref/class_open_maya_1_1_m_px_node.html)：compute 与节点接口。
- [节点类型与 ID](https://help.autodesk.com/cloudhelp/2024/ENU/Maya-SDK/files/Dependency-graph-plug-ins/Maya_SDK_Dependency_graph_plug_ins_DependencyNodeBasics_html.html)：公开分发前检查唯一类型 ID 要求。
- [Maya Python 与线程](https://help.autodesk.com/cloudhelp/2023/ENU/Maya-Scripting/files/GUID-9B5AECBB-B212-4C92-959A-22599760E91A.htm)：主线程限制与调度。
- [Qt6 迁移](https://help.autodesk.com/cloudhelp/2025/ENU/Maya-DEVHELP/files/Whats-New-Whats-Changed/2025-Whats-New-in-API/Qt6Migration.html)：理解 PySide6 与旧版本的差异。

示例的实际运行结果见课程根目录 VALIDATION.md，不将文档存在等同于本机验证通过。
