# 第 6 课：一次动作，怎样正确撤销

目标：加载一个真正的 Python 命令插件，让选中物体沿本地 X 平移属性增加指定厘米数，并支持 Undo / Redo。

## 先约定行为

本例只接受 transform，拒绝 shape、顶点和空选择；translateX 被锁定或输入连接驱动时拒绝整次操作。参数始终以厘米解释，不随界面单位变化。它修改本地 translateX，不保证世界 X 位移，也不绕过动画连接。

打开 [course_move.py](../plug-ins/course_move.py)。入口 initializePlugin 注册 `courseMoveX`，Maya 执行该命令时用 creator 创建一个 MoveX 实例。实例保存这一次操作的 modifier，所以撤销时不必重新猜测用户选中了谁。

## 三个方法的职责

| 方法 | 什么时候执行 | 做什么 |
|---|---|---|
| doIt | 初次调用 | 解析参数、检查全部对象、记录修改，然后调用 redoIt |
| redoIt | 初次执行及重做 | 应用已经准备好的修改 |
| undoIt | 撤销 | 通过 modifier 恢复原值 |

`isUndoable()` 返回 True 只是声明能力，不会替你实现撤销。redoIt 不重新读取选择：用户执行命令后可以改选其他对象，重做仍应作用于原来那些对象。

MDGModifier 可以记录受支持的属性修改，避免手动管理每个旧值。本例先逐一调用 newPlugValueMDistance 排队，全部预检查通过后才 doIt。这样第二个对象被锁定时，第一个也不会提前移动。这个预检查不代表所有任意复杂 Maya 操作都能自动事务化；新增操作时仍需要分析失败后的状态。

## 单位不是细枝末节

`asMDistance().asCentimeters()` 明确读成厘米，写入时构造厘米单位的 MDistance。不要把 cmds.getAttr 得到的界面单位数值与内部厘米直接相加。名称叫 offset、distance 等参数时，应在界面和文档写明单位。

## 在练习场景运行

```python
import maya.cmds as cmds
path = r"D:/Courses/MR_Maya_Plugin_Course/plug-ins/course_move.py"
plugin_name = cmds.loadPlugin(path, quiet=True)[0]
a = cmds.polyCube(name="moveLessonA")[0]
b = cmds.polyCube(name="moveLessonB")[0]
cmds.select(a, b)
cmds.courseMoveX(3.0)
cmds.undo()  # 两个对象恢复
cmds.redo()  # 两个对象再次增加 3 厘米
```

## 故意制造错误

锁住 b.translateX，再选择 a、b 执行命令。应该报错，a 不应移动。再选择一个顶点执行，应该明确拒绝。不要把这些报错当成插件坏了，它们是在保护接口契约。

练习：增加 Y 方向支持。先决定接口是独立命令还是添加轴参数，再确保参数错误时没有场景副作用。提示：不要复制整份类，应该把“选择哪个 plug”作为变化点。

验收：初次执行、撤销、重做均正确；改选后撤销仍作用于原对象；米单位场景输入 100 表示 1 米；无效选择不产生部分修改。

插件卸载和撤销队列的关系见下一阶段的第 8 课，不要在工作场景里用 flushUndo 作为日常重载手段。
