# 第 7 课：让 Maya 按依赖关系计算

命令表示一次动作；节点表示场景内持续存在的数据关系。例如“输出一直等于 A × B”，应让 Maya 在需要时求值，而不是在窗口里反复监听输入变化。

## 先跑出结果

在空白练习场景中运行：

```python
import maya.cmds as cmds
path = r"D:/Courses/MR_Maya_Plugin_Course/plug-ins/course_multiply.py"
plugin_name = cmds.loadPlugin(path, quiet=True)[0]
node = cmds.createNode("courseMultiply")
cmds.setAttr(node + ".inputA", 3)
cmds.setAttr(node + ".inputB", 2)
print(cmds.getAttr(node + ".output"))  # 6.0
cmds.setAttr(node + ".inputA", 5)
print(cmds.getAttr(node + ".output"))  # 10.0
```

## 逐层阅读源码

打开 [course_multiply.py](../plug-ins/course_multiply.py)。initializePlugin 注册类型，不是直接创建场景实例；creator 在创建实例时返回对象；initialize 定义这个类型的属性。

属性定义保存在类字段上，描述节点类型的接口。每个场景实例的实际输入值来自 compute 收到的 data block，不能把 inputA 的数值保存成 Python 类全局变量，否则多个节点实例可能相互污染。

inputA/inputB 是可编辑输入。output 设置 writable=False，阻止把它当普通输入写入；storable=False 表示不把可重算的输出值当作必须存储的数据。

## dirty 的含义

attributeAffects 声明：输入变化时，输出的旧结果不再可信，需要重新计算。这个状态常称为 dirty。只有执行乘法而不声明依赖，首次结果可能对，改输入后却可能读到缓存旧值。

compute 从 data.inputValue 读取输入，经 outputValue 写出结果，最后 setClean 表示该输出已更新。在 Python API 2.0 中，非本节点处理的 plug 走示例中的 `return None`。不要混用其他语言接口的返回约定。

compute 里不要弹窗、改变选择、任意创建节点或把数据写到磁盘。它可能被 Maya 按求值需求多次调用，调用时机不等同于用户按按钮。

## 把关系接起来

```python
driver = cmds.createNode("transform", name="multiplyDriver")
cmds.connectAttr(driver + ".translateX", node + ".inputA")
cmds.setAttr(driver + ".translateX", 4)
print(cmds.getAttr(node + ".output"))
```

在默认厘米练习场景里应看到 8。连接带单位属性时 Maya 可能插入单位转换，观察 Node Editor，而不是假定所有 double 都代表同一个物理含义。

## 类型 ID 与保存场景

文件中的 TYPE_ID 是本地学习示例标识，不代表你拥有可公开分发的唯一产品 ID。和其他插件冲突时不能靠改名称解决；公开发布节点前应按 Autodesk 指引申请唯一 ID。保存场景会留下对节点类型/插件的依赖，所以节点产品比一次性脚本有更长期的兼容责任。

练习：新增 offset 输入，让 output = A × B + offset。必须同时增加属性定义、attributeAffects 和 compute 读取；漏掉其中一项，观察失败症状。

验收：输入变化与输入连接都生效；两个实例互不影响；保存、重开后仍能正确求值。独立测试脚本已经演示了保存重开流程。
